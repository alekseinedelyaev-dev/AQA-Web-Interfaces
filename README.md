# Автоматизированное тестирование веб-интерфейсов

![Java CI with Gradle](https://github.com/alekseinedelyaev-dev/AQA-Web-Interfaces/actions/workflows/gradle.yml/badge.svg)

## Описание проекта

Домашнее задание по курсу «Автоматизированное тестирование»
образовательной платформы Нетология.

Цель проекта — автоматизация тестирования веб-формы
заказа дебетовой карты.

## Используемые технологии

- Java 17
- Gradle
- JUnit 5
- Selenium WebDriver
- WebDriverManager
- GitHub Actions

## Реализованные проверки

1. Успешная отправка заявки с корректными данными.
2. Отправка формы с пустым полем имени.
3. Отправка формы с пустым полем телефона.
4. Отправка формы с двумя пустыми полями.
5. Проверка имени латинскими буквами.
6. Проверка имени с цифрами.
7. Проверка имени со специальными символами.
8. Проверка короткого номера телефона.
9. Проверка длинного номера телефона.
10. Проверка телефона без знака плюс.
11. Проверка отправки формы без согласия на обработку данных.

## Запуск приложения

Для запуска тестируемого приложения необходимо выполнить:

```bash
java -jar ./artifacts/app-order.jar
```

Приложение будет доступно по адресу:

http://localhost:9999

## Запуск автотестов

Для Windows:

```bash
./gradlew.bat clean test
```

Для Linux:

```bash
./gradlew clean test
```

## Отчёт о тестировании

После выполнения тестов HTML-отчёт доступен в папке:

`build/reports/tests/test/index.html`

## Непрерывная интеграция

В проекте настроен GitHub Actions.

При отправке изменений в ветку main автоматически:

- устанавливается Java;
- запускается тестируемое приложение;
- выполняются автотесты;
- формируется отчёт о результатах тестирования.
